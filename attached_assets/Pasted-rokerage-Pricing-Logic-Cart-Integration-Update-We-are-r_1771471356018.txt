rokerage Pricing Logic + Cart Integration Update

We are restructuring the brokerage pricing architecture for clarity, automation, and platform-style positioning.

Implement the following changes:

1️⃣ Remove “Custom Quote” Tier

Delete the $50,000+ → Custom Quote logic entirely.

Replace High-Value structure with standardized flat pricing.

New structure:

A. Low Value Shipment (LVS)

For goods valued under $2,500 CAD
Price: $145 CAD

Includes:

Electronic customs entry (EDI)

Duty & GST calculation

Document review

Release coordination

Standard tariff treatment (MFN)

B. Commercial Import Clearance (Any Value Over $2,500 CAD)

Flat: $295 CAD

Includes:

Full electronic customs entry

Duty & tax calculation

Value validation review

Release coordination

Standard tariff treatment

Basic compliance screening

No value-based tiers.
No percentage model.
No manual quotes.

C. Clearance + Compliance Review (Premium Option)

Price: $395 CAD

Includes everything in Commercial Import Clearance PLUS:

HS code verification (1 line)

Tariff treatment eligibility review (CUSMA / CPTPP / CETA)

SIMA screening flag check

Import control screening (CFIA / EICC / etc.)

Risk summary report

2️⃣ Remove Value Range Toggle Pricing

Delete the current:

$2,500–$10,000

$10,000–$50,000

$50,000+ tiers

Replace with simple:
Under $2,500 → LVS
Over $2,500 → Commercial Clearance

UX must be cleaner and frictionless.

“Select Package”

Any add-on service

Permit submission → Request product details + regulatory category

B2 Correction → Request B3 copy + correction explanation

Make intake modular and conditional.
